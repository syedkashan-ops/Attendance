# Petrol Station Visit & Attendance

Mobile Streamlit app for employee petrol-station IN/OUT attendance.

- GPS captured only when requested
- Pakistan local time (Asia/Karachi)
- Live records in private Google Sheet
- One Excel report per date
- Daily Excel reports archived in a separate private GitHub repository
- Admin password required for report download

Entrypoint: `app.py`

Never commit Google service-account JSON, Streamlit secrets, or GitHub tokens.
